# InfoTech Solutions - Enterprise Web Platform

Official website for InfoTech Solutions - Enterprise Software, ERP, BI & AI Engineering.

## Tech Stack
- Next.js 16 (App Router)
- React 19
- Tailwind CSS
- Lucide React Icons

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Deployment

```bash
npm run build
```
